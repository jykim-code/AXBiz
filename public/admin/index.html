기업을 DART 법인과 연결하면 기업 상세에 회사정보·재무가 자동 표시됩니다. 이름으로 검색해 선택하세요. 해외/미연결은 비워두면 표시되지 않습니다.

검색 별칭은 이용자가 정식 사명 대신 입력하는 표기입니다(엔비디아 → NVIDIA, PCN → 피씨엔, 옛 사명 SK C&C → SK AX). 기업 페이지 검색에만 쓰이고 화면에는 노출되지 않습니다.

컨플 가져오기

가져온 항목은 draft로 적재되어 "검수·배포" 탭과 미리보기에서만 보입니다. 배포해야 라이브에 반영됩니다.

📖 사용 가이드 (클릭해 펼치기)
① 가져오기(데일리/히스토리) 또는 수동 입력→ ② 검수·수정→ ③ 미리보기→ ④ 배포

①~③은 라이브 미반영. 배포를 눌러야 본 사이트에 즉시 반영됩니다.

신규
라이브에 없는 항목 → 검수 후 배포(추가)
교체
라이브와 내용 다름 → 수정 후 배포(덮어씀)
동일
라이브와 같음 → 배포 불필요, 삭제로 정리

DART 미연결 배지가 보이면 새 기업입니다 — 배포 전후 "DART 연결" 탭에서 1회 매핑하면 기업 상세에 재무가 자동 표시됩니다(해외 기업은 매핑 불가, 무시).

위클리 픽

그 주 동향에서 3~5건을 골라 「왜 주목하나」를 한 줄씩 쓰고 발행합니다. 선별과 이유는 사람이 쓰는 것이 원칙입니다(비면 발행되지 않습니다) — 이 한 줄이 없으면 대시보드와 같은 화면이 됩니다. AI 초안은 빈 칸을 메우는 보조이고, 수치는 자동 집계됩니다. 발행하면 그 시점 내용이 고정되어, 원본을 나중에 고쳐도 공유한 링크의 내용은 바뀌지 않습니다.

주차 선택 (그 주 아무 날짜)

태그 관리

지식그래프 고정 핀 태그 (쉼표로 구분)

핀 태그는 빈도와 무관하게 홈 지식그래프에 항상 표시됩니다. 그 외에 공유 태그(2개 기업 이상)와 기업별 대표 태그 3개는 자동 포함됩니다. 데이터에 없는 태그는 무시됩니다.

기업별 태그 관리

태그를 클릭하면 삭제 표시(취소선)됩니다. 삭제는 그 기업의 모든 날짜 항목에서 제거되고, 추가는 모든 항목에 붙습니다. 저장 시 영향 날짜를 자동 재색인합니다. ※ 컨플 재동기화 시 컨플 내용 기준으로 되돌아갈 수 있습니다.

태그 전역 삭제

데이터에서 완전히 제거됩니다. 저장 시 영향 날짜를 자동 재색인합니다.

Admin Guide

관리자 사용 가이드

보고서 데이터를 넣고 → 검수하고 → 발행하는 방법.

전체 흐름
① 데이터 넣기→ ② 검수→ ③ 미리보기 확인→ ④ 배포

⚠️ 관리자가 넣은 데이터는 곧바로 공개되지 않습니다. draft(초안)로 쌓였다가, 검수 후 "배포"를 눌러야 실서비스에 반영됩니다.

화면이 두 개입니다
  • • 운영(Published) ax-biz-radar.pages.dev — 일반 사용자가 보는 실서비스(발행된 데이터만).
  • • 검수 미리보기(Staging) 상단 "검수 미리보기 ↗" 버튼 — 관리자 전용. draft까지 합쳐 "발행하면 이렇게 보인다"를 미리 확인.
① 데이터 넣기 (모두 draft로)
  • • [가져오기] 탭 — 데일리("…사업동향 [날짜]" 페이지, AI가 섹션 A를 기업별 정리) / 히스토리("AX 동향 히스토리 - 기업" 표) 중 선택 후 컨플 URL 붙여넣기.
  • • [수동 입력] 탭 — 날짜 선택 → 기업 추가 → 입력 → "draft로 저장 → 검수". (기존 항목은 "불러오기"로 수정)
② 검수 — [검수·배포] 탭

draft 항목에 상태 배지가 붙습니다:

신규
실서비스에 없음 → 확인 후 배포
교체
내용 다름 → 수정 후 배포(덮어씀)
동일
변경 없음 → 삭제로 정리

항목별 편집·삭제 가능. DART 미연결 배지는 처음 등장한 기업(아래 참고).

③ 미리보기 — 상단 [검수 미리보기 ↗]
  • • 클릭 → 새 탭에서 PIN 한 번 더 입력(주소가 달라 정상). 상단 검은 "DEV 프리뷰" 배너 + draft 합본 화면.
  • • 사이드바로 검색·기업 이동해도 미리보기 유지. 빠져나오려면 배너의 "실서비스 보기".
  • • 미반영(의도): 검색의 자연어(AI) 질문·기업 AI 요약 밴드는 발행 후 갱신. 카드·그래프·타임라인은 draft 모두 표시.
④ 배포 (발행)

[검수·배포] 탭 또는 미리보기 배너에서 건별 / 날짜별 / 전체 배포. 누르면 즉시 실서비스 반영, 같은 (날짜·기업)은 덮어씀.

DART 연결 (재무 표시)
  • • 이미 연결된 기업은 자동 표시. 처음 등장한 기업(DART 미연결 배지)만 [DART 연결] 탭에서 이름 검색→선택해 1회 매핑.
  • • 해외/비상장 등 DART 대상이 아니면 매핑 안 해도 됨(재무만 미표시).
자주 묻는 것
  • • 넣었는데 실서비스에 안 보여요 → 정상(draft). 검수·배포 탭에서 배포 필요.
  • • 미리보기 PIN을 또 물어봐요 → 주소(도메인)가 달라서. 한 번 넣으면 유지.
  • • 같은 컨플을 또 가져오면? → 같은 항목은 갱신(중복 안 쌓임). 안 바뀐 건 동일 → 삭제로 정리.
